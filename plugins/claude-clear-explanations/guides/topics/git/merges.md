A merge conflict is two incompatible edits that need a person's decision. For a
merge example, state whether both branches have changed since their shared
version. Git can combine many text edits, but conflicting changes still need
resolution. An image file does not generally support the same line-based merge
as text. Selecting one whole image can resolve a conflict; combining parts of
two images may require an image editor. Neither a branch nor an image
guarantees automatic merging.
