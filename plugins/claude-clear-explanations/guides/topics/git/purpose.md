Git keeps selected versions of a project so you can inspect an earlier
version or restore its file contents. You choose when to record a version.
Saving a file in an editor does not make a Git commit.

Imagine you are painting on a computer. You finish an outline and deliberately
keep that version. Later you add a blue sky and keep another version. Then you
try an orange sky. If you prefer the blue one, the earlier recorded version is
still available to inspect or restore.

For an open introduction, finish this version-history example. Do not add
operations the question did not ask for.
