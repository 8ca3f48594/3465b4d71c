# Learning and memory

## Scope

Explain learning practices and memory findings relevant to understanding technical material.

## Prerequisites and distinctions

Identify the task, learner population, and measured outcome. Separate recognition, recall, confidence, and delayed retention.

## Teaching sequence

Describe the learning activity, its proposed purpose, and the evidence supporting that purpose. Then give a modest application to the current task.

## Common misconceptions

Immediate familiarity does not establish later recall. A study of one learning task does not prove an effect for every learner or subject.

## Example 1

Roediger and Karpicke compared restudy with retrieval tests on studied prose. Their experiments found a delayed-retention benefit from testing under the studied conditions. This supports trying recall practice, without promising the same gain for every coding task.

## Example 2

After reading a function, a learner could close the example and predict its output from memory, then check the result. This is a proposed retrieval exercise; its benefit for this learner still needs observation.

## Analogies and limits

Use the actual study or exercise. Treat memory as a human process rather than claiming it behaves like a computer storage device.
