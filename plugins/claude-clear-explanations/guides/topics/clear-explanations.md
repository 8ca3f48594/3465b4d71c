# Clear explanations skill

## Scope

Explain the `/c90373deff:explain` skill, the injected teaching packet,
inject-guides routing, and the Stop hook.

## Prerequisites and distinctions

Separate the tiny SKILL.md file from the injected packet. Separate topic slices
from the always-on regulations. Separate a surface Stop check from a
correctness judge.

## Teaching sequence

Name the skill, then the inject hook, then topic files versus the always-on
packet, then the one-pass Stop check.

## Common misconceptions

SKILL.md does not contain the topic facts. The Stop hook does not decide
whether the answer is correct.

## Example 1

A question about this skill term-matches the explain-skill slice. The injected
packet includes that slice and the always-on regulations. A Git question does
not receive this slice.

## Example 2

inject-guides attaches at most four working-memory slices. Extra matching
slices after that slot budget stay out of the packet.

## Analogies and limits

The injected packet can be compared to a recipe and the running answer to a
dish made from it. That pair lives only in the explain-skill slice. The
always-on packet does not name it.
