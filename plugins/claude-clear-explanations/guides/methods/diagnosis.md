# Explain a diagnosis

State the symptom and the expected behavior. Identify the evidence that narrows
the cause, then trace the mechanism from the cause to the symptom. Distinguish
an observed defect from a hypothesis awaiting a test.

Describe the smallest test that can discriminate between the remaining causes.
Explain how the proposed correction changes the failing condition. State what
has been verified and which behavior remains untested. Preserve the observed
error message and relevant environmental constraints.
