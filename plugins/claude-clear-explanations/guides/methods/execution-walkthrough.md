# Trace execution

Start with the input and expected output. Follow one concrete execution path in
time order. Name exact functions and variables, show state changes, and identify
the point at which control moves to another component.

For asynchronous work, distinguish the order of starting operations from the
order of completing them. Explain branches and failure paths when they affect
the question. Mark unknown implementation details explicitly. Finish by tying
the resulting state to the observed output.
