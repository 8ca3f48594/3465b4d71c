# Explain a cause

State the observed result. Identify the initial condition and trace the actions
that produce the result. Name the component responsible for each change and the
evidence supporting the connection.

Choose an example that preserves this causal relationship. Track the state
before and after each relevant action. For a simile, connect its actions and
conditions to the real mechanism and state where the connection stops. Use a
small change in a condition when it helps explain why the result depends on it.

Separate a demonstrated cause from a plausible explanation. State the condition
under which the causal account holds. When several causes are possible, explain
which observation would distinguish them. Keep correlations at their supported
strength and check whether a common cause could account for both observations.
