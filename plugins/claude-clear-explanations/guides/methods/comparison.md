# Compare alternatives

Identify the decision and the constraints that matter to this reader. Compare
the alternatives using the same criteria and the same workload assumptions.
Explain the mechanism behind each material difference.

Give a recommendation when the evidence supports one. State the strongest cost
or limitation of that choice and the condition that would change the decision.
Keep unmeasured performance and price differences explicit as unknowns. Use a
table only when common criteria make it easier to compare the options.
