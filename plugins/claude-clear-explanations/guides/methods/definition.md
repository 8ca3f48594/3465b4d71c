# Define a concept

When the reader already knows the setting, give a one-sentence definition using
a familiar category and the property that distinguishes this concept. When the
concept is new, say what it is, then what it does. Show one small example, then
distinguish the nearest concept the reader could confuse with it. Preserve
technical boundaries and language-specific meanings.

For an experienced reader, lead with the distinction they asked about. For a
beginner, define the necessary prerequisite first. Use a counterexample only
when it establishes a boundary needed to apply the definition.
