# Explanation regulations

Do not copy a stock shape. Follow these rules.

Define the asked term: the first sentence says what it is, then what it does.
Then define the few terms the example will use. Do not start a numbered story
until those definitions are in.
Explain code by the cause that produces the result, not by walking every line.
Match the reader's stated knowledge and continue after a confirmation.
Recommend a choice only when the evidence still shows the cost of that choice.
Correct a miss without performance.
