# RED: Git openings must name the subject

Date: 2026-09-21. Command: `node --test tests/native-routing.test.mjs tests/eval-corpus.test.mjs`.

Jackson's recorded teaching complaint is that a Git excerpt lacked an introduction
and made the subject hard to identify. Before this change, a painting-and-branch
excerpt with no "Git" in the first paragraph produced `shouldBlock: false`, and a
native prompt that included `I understand saving a file and making a commit`
still injected the commit slice. Those tests failed first. Implementation followed.
The tests were not weakened.
